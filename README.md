# Azure-VM-Hypervisor-Lab
An automated test and deployment pipeline for custom hypervisors leveraging Microsoft Azure Compute and GitHub Actions. 
## Description
An automated virtualization lab hosted on Microsoft Azure. Uses Azure Virtual Machines and ephemeral Spot instances managed via GitHub Actions to boot, test, and tear down custom hypervisor builds in an isolated cloud sandbox.

## Project Overview

## Step 1: Deploy the Azure Host VM & Enable Auto-Shutdown

1. Log in to the Azure Portal.
2.  Select Create a resource > Virtual Machine.
3.  Basics Tab:
	- Project Details: Select your subscription and create a new Resource Group named rg-hypervisor-labs.
	- Instance Details: Name your VM azure-hypervisor-host.
	- Security type: Crucial Step! Change this from "Trusted Launch" to Standard. (Nested virtualization will fail if Trusted Launch blocks hypervisor extensions).
	- Image: Select Windows Server 2022 Datacenter: Azure Edition.
	- Size: Click See all sizes and choose Standard_D4s_v5 (4 vCPUs, 16 GB RAM). This size explicitly supports nested virtualization.
	- Administrator account: Define a secure username and password.
	- Inbound port rules: Select Allow selected ports and check RDP (3389).

4. Management Tab:
	- Scroll down to the Identity and automation (or Operations) section.
	- Enable auto-shutdown: Crucial Safety Step! Enabling this function stops the machine from running while not in use.
	- Shutdown time: Set a time you are comfortable with outside of project hours.
	- Time zone: Select your local time zone.

5. Review + create: Click through to the final tab, wait for validation to pass, and click Create.


## Step 2: Install the Hyper-V Hypervisor Role

1. Once deployment finishes, go to the VM resource and click Connect > RDP to download the remote desktop file. Log in using your admin credentials.
<img width="404" height="255" alt="HAB3" src="https://github.com/user-attachments/assets/539e1af3-2e97-4ab9-90c6-137337f44004" />


2. Inside the virtual machine, right-click the Start menu and open PowerShell (Admin).
3. Execute this command to install Hyper-V and its management tools / Install-WindowsFeature -Name Hyper-V -IncludeManagementTools -Restart
4. The VM will instantly reboot. Wait 1–2 minutes, then reconnect to it via RDP
